# P2 学员批量操作

## Goal

复用线索 CSV 的安全预览/确认模式，为学员提供可追踪的创建型导入、受限导出和负责人/标签/班级批量调整，减少重复建档与逐条维护。

## Background

- 学员已有档案、联系人、标签、报名和班级关系，以及详情版本保护和疑似重复提示；没有 CSV 或多选批量入口。
- 学员当前没有运营负责人字段；不能把线索当前负责人或系统操作人推断为历史学员归属。
- 班级调整必须作用于明确的 active enrollment，并复用课程、校区、班级状态、班级/教室容量和版本规则。

## Requirements

### Student Owner

- 新增可空的学员运营负责人及不可变分配历史；候选仅限在学员校区有权限的 owner/admin/campus_manager/consultant，teacher/finance 不能成为负责人。
- 线索转化报名默认使用已冻结的转化业绩归属人，但报名时可调整；直接报名显式选择且未选时保持未分配。
- 历史学员不按线索当前负责人、最近操作人或其他启发式规则回填，提供“未分配”筛选和批量分配入口。
- 学员负责人变化只影响当前运营归属，不改写线索提供人、转化业绩归属、报名事实或历史分析。

### CSV Import and Export

- 学员 CSV 为创建型导入。必填列：姓名、校区编码、主要联系人姓名、主要联系人手机号；可选列：出生日期、状态、负责人邮箱、已有标签。
- 状态缺省为试听；标签只允许引用机构内已有启用标签，不在导入中隐式创建标签。
- 未知/停用/越权校区、负责人或标签、无效日期/状态/手机号、缺少必填值均形成逐行错误。
- 文件内规范化手机号重复，或命中同机构现有学员/任一联系人时阻断该行并返回脱敏候选和受控学员链接；不自动更新、覆盖或合并。
- 导入不创建报名、账单或班级关系。预览和确认都执行大小、行数、列、UTF-8/CSV、公式注入与业务校验；确认按 requestId 幂等。
- 导入允许部分成功：确认只写入有效行，所有有效行在一个事务内一致提交；逐行错误完整返回。系统错误导致整批失败，不把未知提交状态报告为部分成功。
- consultant 可在其有权校区导入学员；owner/admin/campus_manager 可在管理范围导入。包含完整联系人信息的导出仅限 owner/admin/campus_manager，并按当前校区范围裁剪、限制行数和记录审计。

### Atomic Bulk Changes

- owner/admin/campus_manager 可批量设置/清空负责人、增加/移除已有标签、以及把明确的 active enrollment 批量分配到或移出班级；consultant 不执行管理型批量调整。
- 每次操作先预览，列出目标、变化、无变化项和所有阻断原因；预览结果不是锁，不保证提交成功。
- 提交携带 requestId、操作类型和每个目标当前版本。服务端在事务内重新校验成员权限、学员/报名版本、状态、课程/校区、班级/教室容量和重复学员。
- 批量调整采用整批原子语义：任一目标发生并发、越权或业务冲突，全部回滚并返回结构化阻断项，不静默跳过失败记录。
- 标签批量修改保持每个学员至少一个主要联系人等既有档案不变量；班级调整复用 enrollment 生命周期命令与锁顺序，不直接批量更新 `classGroupId`。
- 成功操作写批次结果和必要审计，中央审计只记录批次、动作、数量和目标 ID，不记录完整联系人或 CSV 原文。

## Acceptance Criteria

- [ ] 授权用户可下载模板、预览并确认学员 CSV；有效行可创建、错误行可修复重试，同一请求重放不重复建档。
- [ ] 重复手机号、未知/停用/越权引用和格式错误均精确定位到行，候选手机号脱敏且不自动合并或更新旧档案。
- [ ] 导入只创建学员、主要联系人、负责人归属和标签，不产生报名、账单或班级关系。
- [ ] 管理者可预览并原子提交负责人、标签和班级批量调整；并发、权限、状态或容量变化使整批回滚。
- [ ] 新增学员负责人和分配历史符合候选/继承规则；历史学员保持未分配且可筛选治理，不改写销售归属。
- [ ] 学员导出按当前机构/校区授权裁剪，防公式注入、有硬上限并留下审计；consultant 无法批量导出联系人。
- [ ] PostgreSQL 集成测试、类型检查、Biome、构建及桌面/390px 浏览器验证通过。

## Dependencies and Out of Scope

- 复用现有线索 CSV 请求大小契约、学员版本、重复候选、enrollment 生命周期和班级容量规则。
- 不提供 Excel/XLSX、自动合并、导入更新、跨机构迁移、批量开单/报名/扣课、导入中创建标签或智能负责人推断。

## Rollout and Rollback

- 负责人字段先以 nullable additive migration 上线，历史行不回填；应用同时支持未分配筛选后再开放导入和批量入口。
- 回滚时关闭批量入口和新写路径，保留已产生的负责人历史、导入批次与审计；现有单条学员、报名和班级流程继续读取兼容字段。
