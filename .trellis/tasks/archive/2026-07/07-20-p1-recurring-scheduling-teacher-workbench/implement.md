# P1 实施计划：周期排课、未来课次调整与教师工作台

## Execution Order

1. **数据库模型与迁移**
   - 扩展 `training.ts`：周期规则、排课批次、lesson 来源/版本/完成字段、attendance 草稿责任字段、教师绑定唯一索引和审计 action。
   - 生成并审查 Drizzle migration，确认旧课次/考勤无需回填，新增字段 nullable/default 安全，索引与外键删除策略符合历史保留。
   - 同步 schema exports 和 migration meta；不使用破坏性 `db:push`。

2. **共享排程领域内核**
   - 在 DB 教务 repository 中抽取并复用：上海时区候选展开、课程时长派生、教室规范化、未来状态判断、教师归属和批次内/外冲突检测。
   - 让既有单节创建继续走同一冲突语义，避免新旧路径漂移。
   - 增加稳定候选键、批次上限、载荷规范化与请求指纹工具。

3. **周期规则与生成事务**
   - 实现规则列表、创建、多规则校验、生成预览、原子生成和幂等重放。
   - 实现规则修改预览/提交、revision 并发保护、人工例外保留/重套。
   - 实现停用决策树：按事务当前时间检测规则关联的未来 `scheduled` 课次、仅停用、以统一必填原因逐节留存的未来课次批量取消。
   - 停用规则后拒绝继续生成或同步，且生成提交不得隐式恢复规则。

4. **任意未来课次批量变更**
   - 实现多选预览、统一时间偏移、教师/教室批量赋值和逐条覆盖的服务端输入模型。
   - 按稳定顺序锁定课次，以 transactionNow、status、version、校区范围和资源冲突做全量校验。
   - 原子写课次、规则例外、批次幂等和白名单审计；并发或任一失败零部分更新。

5. **教师成员绑定**
   - 扩展教师 repository/API 契约支持 `userId | null`，提供可绑定的当前 teacher 成员候选。
   - 在机构锁内校验角色、机构和唯一性；成员改角色/移除时阻止留下有效绑定。
   - 补绑定/解绑审计和 API 错误映射。

6. **点名草稿与教师结课授权**
   - 实现教师本人课次查询和资源级授权，保持管理角色原有校区范围路径。
   - 实现课前 30 分钟开放的 attendance 草稿同步，不写课消。
   - 扩展最终结课：结束时间门禁、快捷全勤、草稿名单变化、教学小结、完成时间/人员，并复用既有原子课消与审计。
   - 断言 completed/cancelled 及历史事实不可更新。

7. **Zod 契约、router 与缓存边界**
   - 补 scheduleRules、bulkUpdate、teacherWorkspace 输入输出和共享候选类型。
   - 新增精确角色过程或过程组合，不把 teacher 加入通用教务管理写权限。
   - 同步错误语义、AppRouterClient、查询 key 和所有受影响缓存失效。

8. **教务 Web 操作界面**
   - 从 `academic-workspace.tsx` 拆出周期规则管理、可编辑生成预览、停用确认和未来课次批量调整组件。
   - 支持批量教师/教室、时间偏移、逐行覆盖、冲突定位、陈旧预览刷新和原子提交结果。
   - 保持桌面与移动布局、加载/空/错误/提交中状态，并复用现有 UI 组件与时间格式工具。

9. **教师个人工作台**
   - 新增教师路由和导航权限，只展示当前绑定教师的课表。
   - 实现一键全勤、异常点名、草稿状态、计划结束后的最终结课、预计课消汇总和可选教学小结。
   - 未绑定、名单变化、余额不足、过早操作、重复结课和权限变化提供明确反馈。

10. **测试、文档与集成检查**
    - 扩展 PostgreSQL 教务集成测试和 API 入口测试，覆盖下列矩阵。
    - 更新 README 当前能力和边界；若实施产生新的稳定约束，在收尾阶段更新 teaching/audit/organization spec。
    - 完成类型、Biome、全量集成测试、生产构建和桌面/移动浏览器验收。

## Test Matrix

- 周期：单/多规则、日期边界、多星期、相邻课次、候选内部冲突、既有教师/教室冲突、重复逻辑发生日、停用课程/校区/班级状态。
- 幂等/并发：相同 requestId 重放、不同载荷冲突、两次并发生成、预览后规则 revision 变化、批量更新 version 变化。
- 规则同步：生效日期、普通课次、人工例外保留/重套、completed/cancelled/过去 scheduled 冻结。
- 停用：无未来课次；有未来课次仅停用；缺少取消原因；批量取消；预览后课次状态或时间变化。
- 任意批量：跨班级/规则选择、教师/教室批量值、时间偏移、逐行覆盖、跨校区教师、批次内部冲突、整批回滚。
- 绑定/授权：跨机构、非 teacher 成员、重复绑定、解绑、角色降级/成员移除、未绑定教师、他人课次、校区范围撤销。
- 草稿/结课：提前 30 分钟边界、过早结课、全勤快捷、异常草稿、多次保存、名单变化、余额不足、逾期补结课、重复/并发结课、完成后不可修改。
- 审计：成功恰当 action/实体/校区/白名单前后值；自由文本不入快照；失败零审计；审计失败领域事务回滚。

## Validation

```bash
pnpm db:generate
pnpm db:migrate
pnpm check-types
pnpm test:integration
pnpm check
pnpm build
```

浏览器关键路径：

1. 管理员绑定 teacher 成员账号。
2. 教务创建同班级两条周期规则，预览并修正冲突后生成。
3. 修改规则并处理人工例外；按两条分支停用规则。
4. 任意选择未来课次，批量换教师/教室和偏移时间，再逐行修正并提交。
5. 教师在课前 30 分钟保存异常点名草稿；课后确认结课。
6. 另一节课直接执行全勤并结课；确认已完成事实无法再调整。
7. 在 1440px 桌面和 390px 移动视口检查完整流程。

## Review Gates

- migration 不改写旧 lesson/attendance，不删除历史字段；应用回滚可继续读取既有课次。
- `lesson` 仍是唯一排程事实，`scheduleText` 仅派生展示。
- 周期、规则同步、任意批量和单节创建复用同一冲突/时长实现。
- 教师写权限在 DB 资源层再次校验本人绑定，不依赖前端或 router 角色判断。
- completed/cancelled/过去 scheduled 的写保护由服务端和测试证明，不能只隐藏按钮。
- 草稿不产生课消；最终结课继续锁定完整 current active 名单并保持原有锁顺序。
- 审计不包含取消原因、教学小结、学员名单、联系方式或备注。

## Risky Files And Rollback Points

- `packages/db/src/schema/training.ts` 与新 migration：先审查 nullable/default、唯一索引、外键和 enum 扩展。
- `packages/db/src/repositories/teaching.ts`：按领域块局部拆分，避免继续膨胀单文件；共享锁顺序不得改变。
- `packages/db/src/repositories/organization-management.ts`：教师绑定对成员角色变更的约束应保持小范围，不重写成员管理。
- `packages/api/src/contracts/training.ts`、`routers/index.ts`：契约变更同步所有调用方，不扩大 teacher 的通用写权限。
- `apps/web/src/features/training/academic-workspace.tsx`：新增功能拆组件，不做无关视觉重构。

回滚顺序：先停用新 UI/API 入口并保留既有单节排课/管理者结课，再回滚应用代码；数据库新增表、字段、规则、批次、草稿和审计事实保留，不执行生产降级删除。
