# P2 运营效率与管理分析

## Goal

在当前产品研发阶段完成可以依靠仓库代码、本地 PostgreSQL、自动化测试和浏览器验证形成闭环的 P2 能力，减少高频重复操作与人工 Excel 汇总，让管理者在系统内查看口径统一、权限受控的经营数据。

本父任务维护当前阶段范围、公共指标口径、子任务顺序和最终集成验收，不直接承载业务代码。依赖真实生产基础设施或生产等量数据的事项不作为当前 P2 完成门槛，转为独立后续需求。

## Background

- P1 教务、学员/报名和财务闭环已完成。
- P2 已交付全局搜索、运营任务、学员批量操作、招生/教学/续费核心指标，以及应收账龄、净回款和 30 日开单 cohort 分析。
- 财务分析已完成本地 PostgreSQL 金值测试、20 万账单 mock 性能验证和有效索引优化；真实生产等量性能复测需要上线前置条件，不能在当前本地研发阶段完成。
- 当前仓库没有稳定的生产对象存储、恶意文件扫描器、报表文件生命周期、外部投递通道或生产调度运行条件。
- 本地演示数据属于研发和验收辅助，不是 Issue #6 的 P2 产品交付项。

## Requirements

### R1. 当前阶段交付范围

- 已完成能力继续作为 P2 验收基线：全局搜索与跨模块跳转、运营任务、学员批量导入导出与原子批量调整、核心经营指标、应收账龄与回款分析。
- 完成教师与班级资源利用分析：教师标准容量历史、实际/计划利用率、班级容量、满班/接近满班和历史课次上座率。
- 完成多维经营对比页面：按权限提供校区、课程、教师和班级比较，复用既有核心、财务和资源指标查询。
- 报表能力缩减为可在当前研发阶段闭环的“个人保存筛选条件 + 当前结果即时 CSV 导出”。
- 页面、下钻、保存筛选和 CSV 导出均使用同一服务端指标口径，并在每次访问时按当前成员、角色、机构和校区重新授权。

### R2. 经营指标与资源口径

- 公共时间范围、`Asia/Shanghai` 自然日、左闭右开区间、指标版本、数据成熟度和无分母语义继续复用已交付的分析 registry。
- 净回款使用有效收款减冲正减已批准退款；应收账龄按查询截止时点从不可变资金与账单调整事实重建。
- 教师实际利用率为已完成授课分钟除以已过去期间有效容量分钟；计划利用率为未取消计划分钟除以对应容量分钟。容量按生效日期保留历史，缺失时显示“未配置”，超过 100% 显示真实超负荷比例。
- 班级当前容量利用率按招生中/进行中班级 active 去重学员席位计算；满班率为达到容量的有效班级占比，90% 至未满为接近满班。历史课次使用发生时容量，补课不重复占长期席位。
- 校区、课程、教师和班级对比由服务端聚合，前端只负责筛选、排序、格式化和受控下钻，不复制经营公式。

### R3. 权限与输出

- owner/admin 查看全机构；campus_manager 查看授权校区；finance 只看授权财务；consultant 只看本人招生和满足样本门槛的脱敏基准；teacher 只看本人利用率及本人班级教学事实。
- 顾问和教师不能看到其他成员实名排名；隐藏对象不能通过排行、计数、导出或下钻被推断。
- 保存筛选只保存受控报表类型、时间范围、维度和筛选值，不保存任意 SQL、任意 URL或权限快照；应用时重新校验并明确提示失效条件。
- 即时导出只支持受控范围的 UTF-8 BOM CSV，复用页面查询、排序、时间口径和指标版本，防止公式注入，不包含隐藏列、敏感自由文本或越权数据。
- 当前阶段不建设异步大结果导出；超出同步行数或时间范围时明确拒绝并提示缩小范围。

### R4. 工程约束

- 机构、角色和校区范围只来自服务端当前成员关系；客户端不得指定租户边界。金额使用整数分，业务时间明确为 `Asia/Shanghai`。
- Zod/oRPC 作为公开契约来源；跨表写入使用事务、版本、唯一约束或幂等键；关键动作可追溯。
- 优先复用 PostgreSQL、Drizzle、TanStack Query、既有通知、审计和 UI，不引入搜索引擎、数仓、BI、对象存储或外部队列作为当前阶段依赖。
- UI 区分加载、空、错误、无权、未配置、样本不足和数据未成熟，并完成桌面及 390px 浏览器验证。
- 每个剩余子任务至少完成相关 PostgreSQL 集成测试、类型检查、Biome 和生产构建验证。

## Acceptance Criteria

- [x] 全局搜索、运营任务和学员批量操作已交付，高频查找、派单和批量维护无需重复线下登记。
- [x] 招生漏斗、顾问转化、到课/补课、消课趋势、续费机会、应收账龄、净回款和 30 日开单 cohort 指标已按统一口径交付。
- [x] 教师实际/计划利用率、班级容量利用率、满班/接近满班和历史课次上座率可在本地 fixture 与集成测试中稳定验收。
- [x] 管理者可按许可范围比较校区、课程、教师和班级，并通过受控下钻定位经营差异。
- [x] 用户可保存个人分析筛选并即时导出与当前页面同口径、同权限、同排序的安全 CSV。
- [x] 剩余三个当前阶段交付通过权限、类型、测试、构建及桌面/移动浏览器验证；P2 完成不依赖外部生产基础设施。
