# P2 运营效率与管理分析实施计划

## Scope Guard

- 父任务不直接实现业务代码，只维护当前阶段范围、子任务顺序和最终集成验收。
- 当前阶段只推进教师/班级资源利用、多维经营对比、保存筛选与即时 CSV。
- 附件、完整定时报表、生产等量性能验收和本地演示数据均不计入当前 P2 完成门槛。

## Ordered Checklist

1. 完成并归档教师与班级资源利用分析，固化容量历史、指标口径和权限测试。
2. 完成并归档多维经营对比页面，复用核心、财务和资源查询，不复制指标公式。
3. 将报表子任务实现为个人保存筛选和同步即时 CSV；加入权限重验、范围限制和公式注入防护。
4. 执行跨任务集成核对：角色矩阵、校区范围、权限收回、时区、指标版本、空/错误/未配置/样本不足状态。
5. 同步用户文档和 Issue #6 状态，完成当前 P2 验收。

## Per-Task Quality Gate

- 需求与实现可映射到子任务验收标准，无外部基础设施隐式依赖。
- 数据库变更有兼容、索引、并发和回滚说明，migration 经过审查。
- API 输入输出、服务端授权和错误语义完整；失败不显示为空数据。
- 相关 PostgreSQL 集成测试、类型检查、Biome 和生产构建通过。
- UI 改动完成桌面与 390px 浏览器验证。

## Final Validation

```bash
pnpm check-types
pnpm test:integration
pnpm check
pnpm build
```

最终按 owner/admin、campus_manager、consultant、finance、teacher 五类视角验证可见范围，并核对权限收回后页面、深链接、保存筛选和导出均不能访问旧范围。

## Deferred Gates

- 附件管理：具备私有对象存储、恶意文件扫描器和对象生命周期运维条件后重新进入实施复核。
- 完整定时报表：具备对象存储、持久 worker、生产调度、文件保留和投递条件后独立规划。
- 生产性能验收：具备生产等量脱敏只读副本、代表性参数和明确阈值后执行，不阻塞当前功能交付。
