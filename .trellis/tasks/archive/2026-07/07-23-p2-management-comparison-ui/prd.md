# P2 多维经营对比页面

## Goal

复用 T5、财务分析和资源分析的统一服务端指标，交付校区、课程、教师和班级经营对比，并把现有 `/analytics` 整合为按角色可理解、可下钻的管理分析入口。

## Requirements

- `/analytics` 使用“经营概览 / 经营对比 / 资源与财务”页内标签；角色无权的标签不请求、不渲染，finance 只看到授权财务分析而不是整页无权。
- 校区、课程、教师、班级比较必须由服务端维度聚合返回，前端只负责筛选、排序和格式化，不重新计算经营公式。
- 授权管理者明细表展示全部真实行；比例分母不足 5 标记样本较少且不进入 Top/Bottom，绝对金额、分钟和课次数不设样本门槛。
- consultant 仅本人招生与至少 5 个结案周期的脱敏校区基准；teacher 仅本人利用率和本人班级教学事实；无权角色不能通过排名、计数或下钻推断隐藏对象。
- 无课程手工账单归入“未关联课程 / 其他业务”，维度合计须与机构/校区总额一致并显示覆盖提示。
- 下钻使用服务端受控游标或既有授权深链接；覆盖加载、错误、空、无权、未配置、样本不足、历史覆盖不足和负数趋势。
- 桌面与 390px 均不得依赖横向滚动才能理解核心指标；不新增图表依赖，复用现有 UI、格式化和轻量 SVG/CSS。

## Acceptance Criteria

- [ ] 三类标签、校区/课程/教师/班级维度和角色视图只调用统一 registry，并与后端金值结果一致。
- [ ] owner/admin、campus_manager、finance、consultant、teacher 的可见标签、范围、排名和下钻均符合父任务角色矩阵。
- [ ] 小样本、未配置容量、财务事实缺口、负数回款、零值、空态和错误态表达清晰且不可混淆。
- [ ] 浏览器验证桌面/390px、自定义范围、标签切换、下钻、无横向溢出，类型检查、Biome 和生产构建通过。

## Dependencies and Out of Scope

- 必须在 T5、财务分析和资源分析查询契约稳定后实施；本任务不得另建平行 SQL 或复制公式。
- 不包含导出、定时报表、保存筛选、预测、目标或跨机构市场基准。
