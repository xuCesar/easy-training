- [x] 设计并实现统一标签导航：经营概览、经营对比、资源与财务；无权标签不触发请求。
- [x] 接入服务端维度聚合契约，补齐校区/课程/教师/班级维度所需的最小 API 类型和权限测试。
- [x] 实现维度筛选、排序、样本门槛、数据质量提示、空/错误/无权状态和受控下钻。
- [ ] 复用现有格式化、表格和轻量 SVG/CSS，完成桌面与 390px 响应式验证（本地服务监听被系统权限阻断）。
- [x] 运行集成测试、类型检查、Biome、生产构建并记录角色矩阵与回滚点；浏览器烟测待本机监听权限恢复后补做。

## 验证命令

```bash
pnpm test:integration
pnpm check-types
pnpm check
pnpm build
```

## 风险与回滚

- 不在前端重算服务端经营公式；发现维度字段缺失时返回数据质量提示并回到统一 API 契约补齐。
- 角色过滤必须在服务端和页面请求层同时生效；页面隐藏不能替代服务端授权。
- 维度表过宽时使用纵向卡片/表格布局，不引入新图表依赖；异常时可回退到原有概览标签。
