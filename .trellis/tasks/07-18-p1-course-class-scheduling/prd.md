# P1 课程产品、班级与排课基础能力

## Goal

建立多校区教培机构可运营的教学主数据闭环：课程产品、教师档案、班级和具体课次。教务人员能够在授权校区开班并排出不冲突的课次，为既有报名转化和后续考勤、课消提供稳定的 `course -> classGroup -> lesson` 边界。

## Confirmed Facts

- 现有数据库已有 `teacher`、`teacher_campus`、`course`、`class_group`、`lesson` 和相关状态枚举，但没有独立维护 API 或 Web 入口。
- 报名转化读取课程和 `recruiting/running` 班级；班级容量、状态和 `scheduleText` 已被使用，不能破坏该路径。
- 运营工作台以 `lesson` 的精确时间、教师、校区和教室展示近期教学安排。
- 机构、校区范围、校区启停和成员角色机制已存在；写事务必须在机构锁内重新计算当前成员授权。
- `teacher_campus` 尚未被业务写路径使用；若不补最小教师档案，班级无法形成可运营闭环。

## Requirements

### R1 课程产品与教师档案

- `owner/admin` 管理机构级课程目录：编码、名称、类别、级别、单次时长、标准价格、课包课次、标签和启用状态；编码在机构内唯一，金额沿用分，时长和课包课次必须为正数。
- 停用课程不得用于新建班级或新的报名转化候选项，但既有线索、报名、班级和课次保留历史展示。
- `owner/admin` 维护最小教师档案：姓名、可选手机号、科目、周容量与一个或多个可授课校区；本期不实现教师端、考勤或薪酬。

### R2 班级

- `owner/admin` 可跨机构内校区管理班级；`campus_manager` 仅可管理其当前可访问且启用的校区；`consultant` 仅通过既有报名流程选择可报名课程/班级，不能维护教务。
- 班级必须属于一个机构、一个启用校区、一门启用课程和一名已归属该校区的主讲教师，容量为正整数，状态限于现有枚举。
- `recruiting/running` 班级可新增课次；`paused/completed` 不可新增。已有关联报名或课次时不可更换课程；容量不得低于现有报名人数。
- `scheduleText` 不再作为可编辑排程事实；本期保留其兼容展示，摘要由课次生成或在没有课次时显示“排课待定”。

### R3 课次与冲突

- 教务可为可排课班级新建单节课次、按校区/班级/日期范围查看课次，并取消已排课次。
- 课次继承班级校区和主讲教师；本期不允许改派教师、改校区或改期。需要变更时取消原课次后重新创建。
- `startsAt < endsAt`，输入和展示统一使用 `Asia/Shanghai`；时间区间采用半开区间 `[startsAt, endsAt)`，首尾相接不冲突。
- 同一教师或同一“校区 + 规范化教室标识”的未取消课次发生时间重叠时必须拒绝。并发排课最多一方成功，任何失败不得产生部分写入。
- 取消仅允许 `scheduled -> cancelled`，保留原资源信息、取消操作者、取消时间和可选原因；取消不影响报名、账单、剩余课时、考勤或课消。

### R4 安全与兼容

- 所有创建、更新、启停、排课和取消事务在写入前重新校验当前成员角色、校区范围、校区启用、机构归属及教师校区归属。
- 新增课程/班级/课次变化应失效运营工作台和报名转化候选缓存；既有报名转化仍只选择当前可报名的课程和班级。
- 不提供物理删除。历史课程、班级与课次保持可读取；本期不实现学员入班、考勤、请假、课消、补课、调课、代课、自动排课或复杂周期规则。

## Acceptance Criteria

- [ ] owner/admin 可管理课程和教师；课程编码机构内唯一，停用课程不能新建班级或出现在新报名候选项。
- [ ] 授权成员可在启用校区创建和维护班级；跨机构资源、未归属校区的教师、停用课程/校区、越权校区与非法容量均被服务端拒绝。
- [ ] `recruiting/running` 班级可被既有报名流程选择；暂停或结课班级不可用于新报名和新增课次。
- [ ] 授权成员可创建、筛选和取消课次；课次校区、教师与班级一致，时间有效。
- [ ] 教师和同校区教室的重叠排课被事务性拒绝；相邻课次与已取消课次不视为冲突，并发冲突最多一方成功。
- [ ] 取消课次保留审计信息，不修改报名、账单、课时、考勤或课消数据。
- [ ] 课程、班级、课次的机构隔离、校区范围、停用校区、资源冲突、容量边界和报名转化兼容均有 PostgreSQL 集成测试。
- [ ] 教务页面覆盖列表、筛选、新建、编辑、取消、加载、空、错误与桌面/移动端状态。

## Out Of Scope

- 考勤、请假、课消、课时扣减、补课、调课、代课和学员入班。
- 自动排课、拖拽日历、复杂周期/节假日规则、批量调课或批量取消。
- 教室主数据、容量、设备与资源图；本期以规范化文本教室标识判定冲突。
- 跨校区班级、跨机构教师、教师端、家校通知、教师薪酬和工时结算。

## Recommended Decisions

- 课程目录保持机构级，仅 owner/admin 管理；campus_manager 可读课程并管理授权校区内班级和课次。
- 最小教师档案与校区归属纳入本任务，避免依赖未暴露的预置数据。
- P0 仅支持单节课次创建与取消；固定周期批量排课作为本阶段验收稳定后的后续能力。
