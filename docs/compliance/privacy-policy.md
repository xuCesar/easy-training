# Easy Training 隐私政策(机构版)

> 状态:草稿 v0.1(2026-07-26)。适用于试运行期。**斜体方括号**处为待机构确认项。
> 本系统为教培机构内部运营系统,个人信息处理者为使用本系统的教培机构;
> 系统运营方作为受托方按机构委托处理数据。

## 一、我们处理哪些个人信息

系统为机构的招生与教学管理目的,处理以下类别的个人信息:

| 类别 | 字段 | 来源 |
| --- | --- | --- |
| 学员基本信息 | 姓名、出生日期 | 机构工作人员录入 |
| 监护人信息 | 监护人姓名、联系电话 | 机构工作人员录入 |
| 其他联系人 | 姓名、电话、与学员关系 | 机构工作人员录入 |
| 报名与就读记录 | 报读课程、班级、出勤、课时消耗 | 系统业务过程产生 |
| 财务记录 | 缴费、退费、票据信息 | 系统业务过程产生 |
| 线索信息 | 潜在学员/家长姓名、电话、跟进记录 | 咨询登记 |
| 员工账号信息 | 姓名、邮箱、登录记录 | 员工注册/受邀加入 |

系统**不采集**:身份证号、人脸等生物识别信息、精确位置信息、设备指纹。

## 二、处理目的与法律依据

- 履行机构与学员监护人之间的教育培训服务合同(报名、排课、考勤、结算)
- 基于监护人同意处理未成年学员的个人信息(见第四条)
- 履行法定义务(财务凭证留存、税务要求)

## 三、存储与安全

- 数据存储于中华人民共和国境内的云服务器,不出境
- 传输全程 TLS 加密;数据库仅内网访问;备份加密存储并异地保存
- 访问控制:机构成员按角色与校区范围授权;运维访问最小化并留痕
- 租户隔离说明:多机构数据隔离通过**服务端应用层的仓储与事务边界**实现,
  未使用数据库级行级安全(RLS)。对外表述统一采用本口径,不得夸大

## 四、未成年人保护

- 学员多为未成年人。机构在收集不满十四周岁未成年人个人信息前,
  **必须取得其监护人的单独同意**(见《告知同意书》),并仅在实现
  教学管理目的所必需的范围内处理
- 监护人有权查阅、复制、更正、删除其被监护学员的个人信息

## 五、保留期限

| 数据类别 | 保留期限 | 依据 |
| --- | --- | --- |
| 学员及监护人基本信息 | 学员离读后 *[3 年]* | 复读/纠纷处理需要,期满删除或匿名化 |
| 财务记录(缴费、票据) | 自记账年度起 *[≥5 年]* | 会计凭证法定留存 |
| 线索信息 | 最后跟进后 *[1 年]* | 期满删除 |
| 审计日志 | *[180 天]* | 安全追溯 |
| 数据库备份 | 30 天(滚动) | 灾难恢复 |

保留期满后,系统按《数据保留与清理策略》删除或匿名化。

## 六、数据主体权利

监护人或成年学员可通过机构提出:查阅、复制、更正、**导出**、**删除**其个人信息。
机构应在 *[15 个工作日]* 内响应。删除请求涉及法定留存的财务记录时,
采用**匿名化**处理:抹除姓名、电话等直接标识,保留无法识别到个人的财务凭证
(处理规则见《数据保留与清理策略》)。

## 七、共享与委托

- 数据不向任何第三方出售或共享
- 系统基础设施使用腾讯云(服务器、对象存储),按委托处理关系提供
- 如引入短信/邮件等外部触达渠道,将在启用前更新本政策并重新告知

## 八、安全事件

发生个人信息泄露、篡改、丢失时,按《安全事件响应流程》处置:
立即止损、评估影响、*[24 小时]* 内通知受影响监护人及机构负责人,
按法规要求向监管部门报告。
