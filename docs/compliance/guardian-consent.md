# 学员个人信息处理告知同意书(监护人)

> 状态:草稿 v0.1(2026-07-26)。供机构在纸质报名表或电子表单中使用。
> 不满十四周岁未成年人的个人信息属敏感个人信息,须取得监护人**单独同意**。

---

尊敬的家长/监护人:

为向您的孩子提供教育培训服务,**[机构名称]**(以下称"本机构")需要收集和使用
学员及监护人的部分个人信息。请您仔细阅读以下内容:

**一、收集的信息**
学员姓名、出生日期;监护人姓名、联系电话;其他紧急联系人的姓名与电话;
以及报名、上课、考勤、缴费过程中产生的记录。

**二、使用目的**
仅用于:报名注册、课程与班级安排、出勤记录、课时与费用结算、
与您联系沟通学员学习事宜。**不用于**任何广告推送,不向第三方出售或共享。

**三、存储与保护**
信息存储于境内加密服务器,仅本机构经授权的工作人员按职责范围访问。
学员离读后,信息保留 *[3 年]*(用于复读优惠与纠纷处理),期满删除;
缴费记录按会计法规要求留存 *[5 年]* 以上,期满前将做匿名化处理。

**四、您的权利**
您有权随时查阅、复制、更正、导出学员的个人信息,或要求删除
(涉及法定留存的财务凭证将以匿名化方式处理)。
联系方式:*[机构联系电话/负责人]*。

**五、同意声明**

- [ ] 本人已阅读并理解上述告知内容
- [ ] 本人是学员的监护人,**同意**本机构按上述范围和目的处理学员
  (含不满十四周岁未成年人)的个人信息
